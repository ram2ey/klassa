# School MVP scope

The implemented first-deployment plan and acceptance criteria are maintained in [mvp-release.md](mvp-release.md).

One pilot school, three staff roles, six administrator areas. Core flow: enrol and place pupils, daily attendance, classwork/exam marks, immutable term reports, manual Ghana cedi fees and receipts. Parent accounts, SMS, notices, timetables, behaviour and specialist workflows are deferred. Existing tables remain available for later additions.
